
# JalDrop 💧

JalDrop is a mobile-friendly water delivery website demo.

## Features
- Water product listing
- Shopping cart and quantity controls
- Customer checkout form
- Local demo order history
- Responsive mobile design
- Hindi-first interface

## Files
- `index.html` — website structure
- `style.css` — responsive styling
- `script.js` — cart and demo order logic

## Run locally
Open `index.html` in a web browser.

## Deploy with GitHub Pages
1. Upload all files to the root of your repository.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for deployment.

## Important
This is a frontend demonstration only.
It does not provide secure authentication, shared online orders,
supplier accounts, admin authorization, or real payment processing.

Do not use local browser storage for real customer personal information.
Add a properly secured backend before accepting real orders.
Product prices and delivery charges are examples and must be verified.
